## 簡介
- 遊戲標題：來動物園看一點大場面
- 遊戲類型：2D俯瞰視角動作冒險+經營
- 目標平台：PC(Steam)
- USP：玩家在園區內配置各種機關來「自動化」觸發魔物技能, 在「收益」與「魔物失控」之間走鋼索, 挑戰「高風險、高獲利」的經營策略, 同時享有如同《模擬樂園》般的經營與組建樂趣。由於魔物皆由地下城戰鬥中捕獲, 玩家必須在難度遞增的地下城探索中, 磨練操作技巧並解鎖更強大的裝備, 以提升戰鬥能力來捕獲更強大、且更具表演效果的魔物, 進一步擴充園區。在遊戲過程中, 玩家能同時獲得攻略困難地城的刺激感、收集不同種類魔物的收藏欲, 以及透過精心規劃設施達成收益最大化的成就感。

## 核心玩法
玩家在地下城中捕獲魔物, 放置到動物園中, 不同種類魔物會有各自的技能, 每一種技能都有觸發條件, 透過設置機關滿足觸發條件, 讓魔物不斷使用技能「表演」給遊客看, 從而提高動物園名聲, 獲得更多收益。魔物要持續不斷表演的前提是高怒氣值, 但怒氣值過高會造成魔物失控, 破壞牢籠甚至攻擊遊客, 所以玩家需要取得平衡, 在不讓魔物失控的前提下最大化收益。
當玩家想要動物園中有更豐富的魔物種類, 就需要更強大的裝備和道具攻略更高難度的地下城, 更強大的裝備和道具來自於配方解鎖及素材合成, 而配方及素材可以從地下城、在動物園中的魔物, 有些特定技能會產出素材並可透過設施收集、解任務或是特殊遊客取得。
當玩家想要更多動物園設施來豐富園區, 觸發更多魔物技能或是提高效率時, 就需要透過研究去解鎖新要素, 投入研究的方式為解析裝備、道具, 或是消耗金幣、提升園區等級等, 提升等級也可以擴大園區腹地。
總體來說, 遊戲的主循環是「地下城探索→捕獲魔物→動物園經營→收益→解鎖新要素或提升玩家能力→地下城探索」。
